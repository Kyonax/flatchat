# Core

The central service: accounts and sign-in, trust, join tokens, the server registry and approvals, the public world list, bans, mutes and blocks, reports, guardian links, uploads and conversion, the asset store, the gallery and the admin pages.

- Licence: AGPL-3.0-or-later ([LICENSE](LICENSE))
- Planned stack: TypeScript on Node.js 24 LTS, with PostgreSQL (the same whichever client engine wins)
- Status: empty. It starts in Stage 1.
